# frostdev-ops/tap

```sh
brew install --cask frostdev-ops/tap/rimeward
```

Installs the [Rimeward](https://github.com/frostdev-ops/rimeward) desktop app. Apple Silicon, macOS 14 or newer. The app updates itself; `brew upgrade --greedy` also works.

The cask is bumped by `frostdev-ops/rimeward`'s `homebrew.yml` workflow when a `desktop-v*` release is published.
